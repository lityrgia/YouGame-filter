# YouGame Forum Filter

Расширение для Chrome/Chromium и Firefox, которое добавляет возле «Создать тему» кнопку игнорирования раздела YouGame. Оно скрывает темы только на главной в блоках «Последние ответы», «Новые темы», «Маркет», «Новости форума», «Популярные темы» и «Розыгрыши», а также в `/whats-new/`, `/whats-new/posts/`, `/whats-new/latest-activity` и `/featured/`. В остальных разделах форума темы остаются видимыми.

## Установка

### Chrome, Chromium, Edge, Brave

1. Скачайте `yougame-forum-filter-chrome.zip` из GitHub Releases и распакуйте его.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика» и выберите «Загрузить распакованное расширение».
4. Укажите распакованную папку.

### Firefox

1. Скачайте `yougame-forum-filter-firefox.xpi` из GitHub Releases.
2. Для локальной проверки откройте `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» и выберите файл `.xpi`.
3. Для постоянной установки в обычном Firefox дополнение должно быть подписано и опубликовано через Mozilla Add-ons (AMO).

## Управление

На странице раздела кнопка «Игнорировать раздел» находится слева от «Создать тему» и после нажатия меняется на «Игнорируется». Повторное нажатие отменяет игнорирование. Popup показывает название текущего раздела и сохраняет его в списке игнорируемых; ID там не отображается. При первом запуске в игнор добавлены «Майнкрафт» и «ИИ»; их можно убрать обычной кнопкой. Также доступен импорт и экспорт списка в JSON.

Импорт заменяет текущий список. Экспорт создаёт файл, который можно перенести в другой браузер.

Игнорируемые темы, чей раздел уже есть в локальном кэше расширения, скрываются до первого отображения страницы. Для ранее не встречавшейся темы требуется однократная проверка её страницы; после этого она также скрывается сразу при последующих загрузках.

После скрытия тем расширение пересчитывает штатное чередование фона YouGame только по оставшимся видимым карточкам.

## Сборка из исходников

Требуются Node.js 20+ и утилита `zip`.

```bash
npm run check
npm run package:all
```

Сборки появятся в `release/`: ZIP для Chromium-браузеров и XPI для Firefox. GitHub Actions выполняет эти же проверки при каждом push и pull request.
