# Privacy policy

YouGame Forum Filter does not collect, sell, or send personal data to any third party.

The extension stores its settings and a temporary mapping of thread IDs to forum IDs in the browser's local extension storage. It reads pages on `yougame.biz` only to add the control and filter the requested lists. Network requests are made only to `yougame.biz` and use the active browser session to identify a thread's forum section.

Removing the extension removes its local storage in normal browser configurations.
